# The Camellia Sơn Trà

Hướng dẫn làm việc của repo này là **`AGENTS.project.md`** (ưu tiên) và **`docs/HANDOVER.md`**.

File này từng chứa hợp đồng sandbox Grok Build (cổng `8080`, `startup.sh`, preview proxy, brand-asset pass). Hợp đồng đó không điều khiển site production trên Vercel. Đừng thêm lại.

Chạy local và build: xem `README.md`. Script `npm run dev` trong `package.json` vẫn bind `0.0.0.0:8080` — đó là lệnh dev hiện tại, không phải quy tắc deploy.
